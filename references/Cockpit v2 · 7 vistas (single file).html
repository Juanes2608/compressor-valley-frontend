✓Validación · 4 puntos críticos
✓
Sidebar /admin distinguible — fondo n-975 (más oscura que n-950 de /ops), filete royal 1 px borde derecho, header textual "PANEL ADMINISTRATIVO" con dot pulsante info, logo en info-d, active state Dashboard en info-500. Cinco señales redundantes garantizan reconocimiento instantáneo del shell incluso en periferia visual.
✓
KPIs F15 sin saturar — número mono 22 px protagonista, sub-textos en sans 11.5 px con dots de color (p-600 productos / info-d servicios / n-700 compras / warn-700 devoluciones). Periodo segmented arriba a la derecha (Hoy/Semana/Mes/Año), no compite con el dato. Jerarquía intacta: dato → desglose → contexto.
✓
"Atención requerida" como teaser — header con icono triangular alerta + count "3 urgentes" + meta "Top 3 de 8 alertas". Footer con "Las 5 restantes son de prioridad media" + link explícito "Ver todas las alertas (8)" como destino claro al módulo Alertas. CTAs por item (Aprobar/Recordar/Crear OC) son shortcuts, no reemplazo del módulo.
✓
Grilla 2×2 estratégica, no genérica — cada bloque responde a una pregunta operativa: ¿qué necesito reabastecer? (Productos en alerta → Reorden), ¿quién está trabajando en qué? (OTs en proceso), ¿qué oportunidades comerciales se me escapan? (Cotizaciones por vencer), ¿qué pasó hoy en mi operación? (Actividad reciente). Cada bloque cierra con un link al módulo profundo correspondiente.

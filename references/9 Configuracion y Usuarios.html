Acción restringida

Eres el único Admin activo del sistema. Algunos cambios sobre tu propia cuenta están bloqueados por seguridad para prevenir pérdida de control administrativo.

  • No puedes desactivar tu propia cuenta.
  • No puedes cambiar tu rol a uno inferior a Admin.
  • No puedes eliminar tu cuenta.
Para reasignar permisos Admin a otro usuario y luego editar tu cuenta:
  1. Crea otro usuario con rol Admin o promueve un usuario existente.
  2. Verifica que el nuevo Admin haya iniciado sesión correctamente.
  3. Vuelve a este panel y edita tu propia cuenta con las nuevas restricciones desbloqueadas.
